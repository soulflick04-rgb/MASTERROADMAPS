# MasterRoadmaps — Static Site

Master any skill in 30 days. 100% HTML + CSS + vanilla JavaScript.
No backend, no API keys, no database — works offline.

## Files
- `index.html` — the whole website
- `style.css` — black + orange neon theme, glassmorphism, animations
- `script.js` — roadmap generation, timetable, PDF download, phone validation
- `creator.png` — About Me photo

## Run locally
Just open `index.html` in any browser. That's it.

## Deploy free
**GitHub Pages:** push this folder to a repo → Settings → Pages → deploy from main branch.
**Netlify:** drag and drop this folder at https://app.netlify.com/drop

## Notes
- Roadmaps are generated instantly from smart templates (the typed skill is inserted everywhere).
- The PDF download asks for an Indian mobile number (validated, remembered locally — not stored anywhere).
